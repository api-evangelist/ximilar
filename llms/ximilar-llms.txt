# Ximilar API Documentation

> Ximilar API offers powerful AI Image Recognition, Image Tagging, Visual Search
> services, Collectibles Recognition and more. This is the REST API documentation
> of ximilar.com services for developers.

To get started, sign up at https://app.ximilar.com/login, get your API token from
settings and make sure an appropriate pricing plan is activated
(https://ximilar.com/pricing). The complete documentation in a single file is
available at https://docs.ximilar.com/llms-full.txt.
